1. **Estructura Fiel al Boceto de Referencia**:

2. **Diseño & Experiencia de Usuario**:
   - **Temática Informática Minimalista**: Tipografía técnica (`Fira Code` + `Plus Jakarta Sans`), efectos de brillo suave (*ambient glow*), malla cibernética sutil de fondo y badges de código.
   - **Modo Oscuro / Modo Claro**: Botón interactivo para alternar entre el tema *Dark Terminal* y el tema *Minimal Paper*.

   - **Exportación a PDF**: Hoja de estilos de impresión (`@media print`) calibrada para generar un documento PDF limpio y formal con un solo clic.
   - **Copiar Datos**: Botón para copiar al portapapeles una ficha de contacto resumida con un mensaje tipo Toast.

## 🌐 Cómo Publicarla Gratis en Internet

Puedes alojar esta página sin costo en pocos minutos para que los reclutadores puedan verla desde cualquier lugar:

### Opción 1: GitHub Pages (Recomendada para programadores)
1. Crea un repositorio en GitHub llamado por ejemplo `irvin-ramos-cv`.
2. Sube estos archivos (`index.html`, `styles.css`, `script.js` y la carpeta `assets/`).
3. Ve a **Settings** > **Pages** y selecciona la rama `main`.
4. En 1 minuto tendrás una URL como `https://tuusuario.github.io/irvin-ramos-cv/`.

### Opción 2: Vercel o Netlify
- Solo arrastra y suelta la carpeta `cv-irvin-ramos` en [netlify.com/drop](https://app.netlify.com/drop) para tener un enlace web en vivo al instante.
